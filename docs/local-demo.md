# اجرای مدار روی کامپیوتر خودتان

> رایگان، برای تست و توسعه. همان نسخه‌ای که روی سرور اجرا می‌شود، با شرکت نمونه «زرین‌مدار»، روی آدرس `https://localhost`.
> برای اینکه شرکت پایلوت از گوشی خودش و از بیرون ببیند، بعداً سرور لازم است (`docs/deploy.md`).

## ۱. پیش‌نیازها (یک بار)

| مورد | توضیح |
|---|---|
| **کامپیوتر** | حداقل ۸ گیگ رم و ۱۵ گیگ فضای خالی. ساختن برنامه بار اول ۱۰ تا ۲۰ دقیقه طول می‌کشد؛ اجرای آن سبک است |
| **Docker Desktop** | از سایت Docker. سایت از ایران بسته است؛ فایل نصب را از یک آینه داخلی یا با دسترسی دیگر بگیرید |
| **ویندوز** | WSL2 با Ubuntu (در PowerShell مدیر: `wsl --install`)، و در تنظیمات Docker Desktop: Resources ← WSL integration ← Ubuntu روشن. همه فرمان‌های پایین را در ترمینال Ubuntu بزنید |
| **مک** | Docker Desktop و برنامه Terminal کافی است |
| **Git** | ویندوز (داخل Ubuntu): `sudo apt install -y git`؛ مک: بار اول خودش پیشنهاد نصب می‌دهد |

**اگر Docker Hub یا npm بسته بود** (تحریم):
1. در Docker Desktop: Settings ← Docker Engine، آدرس آینه داخلی را اضافه کنید و Apply بزنید:
   ```json
   "registry-mirrors": ["https://<آینه-داخلی>"]
   ```
2. بار اول آینه‌ها را به اسکریپت هم بدهید (بخش ۲).

## ۲. اجرای بار اول

```bash
git clone <آدرس مخزن> ~/madar && cd ~/madar
scripts/deploy/local-demo.sh
```

با آینه داخلی:
```bash
MADAR_BASE_REGISTRY=<آینه-داکر>/library MADAR_NPM_REGISTRY=<آینه-npm> scripts/deploy/local-demo.sh
```

در پایان، آدرس و رمز چاپ می‌شود:
- **آدرس:** `https://localhost`. مرورگر یک بار درباره گواهی محلی هشدار می‌دهد؛ «Advanced» ← «Proceed» را بزنید.
- **حساب‌ها:** `leila.sadeghi` (مدیرعامل)، `maryam.ahmadi` (مدیر پشتیبانی)، `ali.rezaei` (کارمند).
- **رمز همه:** رمزی که اسکریپت چاپ می‌کند (در فایل `.env.local-demo`، خط `DEMO_PASSWORD`).

اگر پیام داد پورت ۸۰ یا ۴۴۳ گرفته است، برنامه‌ای که از آن استفاده می‌کند را ببندید (مثلاً Skype یا IIS در ویندوز).

## ۳. کار روزمره

| کار | فرمان |
|---|---|
| خاموش کردن (داده می‌ماند) | `scripts/deploy/local-demo.sh stop` |
| روشن کردن دوباره | `scripts/deploy/local-demo.sh start` |
| داده نمونه تازه | `scripts/deploy/local-demo.sh reset` |
| به‌روزرسانی به آخرین نسخه کد | `git pull && scripts/deploy/local-demo.sh` |
| پاک کردن کامل | `scripts/deploy/local-demo.sh remove` |

داده نمونه هر شب ساعت ۵ صبح هم خودکار تازه می‌شود، اگر کامپیوتر روشن باشد.

## ۴. محدودیت‌های نسخه محلی

- **دیدن از گوشی:** فقط روی همان کامپیوتر باز می‌شود. برای اینکه گوشی‌های همان Wi‑Fi هم ببینند، در `.env.local-demo` به جای `localhost`، IP کامپیوتر را بنویسید (`MADAR_DOMAIN=192.168.1.20`) و دوباره `local-demo.sh` را اجرا کنید. گوشی هم هشدار گواهی می‌دهد.
- **نصب روی صفحه اصلی و اعلان گوشی:** به گواهی واقعی نیاز دارند، پس فقط روی سرور با دامنه کار می‌کنند. اعلان داخل برنامه و به‌روزرسانی زنده در نسخه محلی هم کار می‌کنند.
- **رمزها و داده:** نسخه محلی فقط برای تست است؛ داده واقعی شرکت را رویش نگذارید.
